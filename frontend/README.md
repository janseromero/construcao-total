# Construtor Total — Frontend

Next.js 14 (App Router) + TypeScript.

## Estrutura

```
app/
  layout.tsx
  page.tsx
  globals.css
public/        # estáticos (a criar)
```

## Comandos

A partir da raiz do repo: `make up` sobe junto com backend e DB.

Localmente sem Docker:

```bash
npm install
npm run dev
```

## Design

Aderente às diretrizes em `docs/planning/mvp.md §3.4`. Sem gradiente colorido,
sem vibe de "AI app". Paleta concreto/aço/amarelo segurança.
